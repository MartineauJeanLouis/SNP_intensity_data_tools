# Contributing

Thank you for your interest in contributing to `SNP_intensity_data_tools`.

We welcome contributions that improve the workflow, documentation, reproducibility, portability, and usability of this repository.

## How to contribute

There are several ways to contribute:

- report bugs
- suggest new features or improvements
- improve documentation
- submit code changes
- help improve test coverage and reproducibility

## Before you start

Please:

1. read the `README.md`
2. review the project structure and current workflow behavior
3. check whether an issue or pull request already addresses the same topic
4. open an issue first for major changes so the approach can be discussed before implementation

## Development principles

When contributing, please aim to:

- keep the workflow reproducible
- prefer configuration-driven behavior over hard-coded paths or filenames
- document any new dependency or runtime assumption
- avoid committing large generated outputs or third-party binary assets unless clearly justified
- keep changes focused and well-scoped
- preserve compatibility with the existing workflow unless intentionally changing behavior

## Recommended workflow

1. Fork the repository.
2. Create a new branch for your change.
3. Make your edits.
4. Update documentation if needed.
5. Test your changes locally.
6. Submit a pull request with a clear explanation.
